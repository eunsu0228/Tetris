# 이미지 폴더

이 폴더에는 프로젝트 관련 이미지 파일들이 저장됩니다.

## 게임 스크린샷 촬영 방법

1. 게임을 실행합니다:
   ```bash
   python tetris.py
   ```

2. Windows에서 스크린샷을 찍습니다:
   - **전체 화면**: `Win + PrtScn` (자동 저장)
   - **선택 영역**: `Win + Shift + S` (클립보드에 복사)
   - **게임 창만**: 게임 창을 선택한 상태에서 `Alt + PrtScn`

3. 스크린샷을 이 폴더에 저장합니다:
   - 파일명: `gameplay_screenshot.png`
   
4. 또는 그림판이나 다른 편집 프로그램에서:
   - 클립보드의 이미지를 붙여넣기 (`Ctrl + V`)
   - `images/gameplay_screenshot.png`로 저장

## 권장 스크린샷

다음과 같은 장면의 스크린샷이 좋습니다:
- ✅ 양쪽 플레이어가 모두 플레이 중인 화면
- ✅ 다음 블록 미리보기가 보이는 화면
- ✅ 중앙의 "VS" 텍스트가 보이는 화면
- ✅ 하단의 조작 안내가 보이는 화면
